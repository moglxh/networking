# Networking

This repository contains notes, packet captures, experiments, and research related to computer networking.

The focus is on understanding how systems communicate across local and wide area networks, how protocols operate, and how network behavior can be observed and analyzed.

Material is organized around practical observation, packet analysis, and protocol behavior rather than certification-oriented study.

## Areas Covered

* TCP/IP
* Ethernet
* ARP
* ICMP
* DNS
* DHCP
* Routing
* HTTP
* TLS
* VPN Technologies
* Packet Analysis
* Network Troubleshooting

## Repository Structure

```text
dns/
tcp-ip/
http/
tls/
wireshark/
routing/
```

## Purpose

The objective of this repository is to develop a practical understanding of modern networking by combining protocol study with packet captures, lab exercises, and real-world observations.

Where possible, concepts are validated using tools such as Wireshark, tcpdump, dig, and other networking utilities.

## Tools

* Wireshark
* tcpdump
* dig
* host
* traceroute
* ss
* iproute2
